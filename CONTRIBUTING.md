# Contributing

Thanks for taking a look. Roadletter Lite is built in public, one stage per week, and the history is meant to be readable step by step. That shapes how contributions work.

## Issues

Issues are welcome for:

- bugs, in any stage that has been released
- questions about the build: why something is done the way it is, or how a stage works

## Feature requests

Feature requests are politely declined. Roadletter Lite does one thing: send one newsletter in a legally sound way. Anything beyond that stays out, even good ideas.

Lite stays small.

## Pull requests

Please open an issue first and wait for a reply before sending a pull request. That keeps the build readable: each change should fit a stage and be easy to follow later.

## Security

Please don't report vulnerabilities in public issues. See [SECURITY.md](SECURITY.md).
