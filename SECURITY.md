# Security

## Reporting a vulnerability

Please report vulnerabilities privately, not in a public issue.

Use GitHub's private vulnerability reporting: open the **Security** tab of this repository and choose **Report a vulnerability**. Only the maintainer can see the report.

Please include what you found, how to reproduce it, and which version or commit you tested.

## What happens next

- You'll get a first reply within 7 days.
- Once the issue is confirmed, a fix goes into the next release, and the release note credits you unless you'd rather not be named.

## Supported versions

Only the latest tag gets security fixes.

Roadletter Lite is built in public, one stage at a time, and isn't usable yet. Until v1.0, reports are still welcome; they just help shape the build rather than patch a running system.
