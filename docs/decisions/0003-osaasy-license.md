# 0003: O'Saasy License

- Status: Accepted
- Date: 2026-10-19

## Context
The code should be readable and usable by anyone who wants to run their own newsletter, change it or learn from the build. At the same time, nobody should be able to take it and run it as a competing hosted service. A permissive license allows that; a strict copyleft license doesn't prevent it either.

## Decision
Roadletter Lite is source-available under the O'Saasy License. Using, changing, reselling and redistributing self-hosted copies is allowed; offering the software as a competing hosted or managed service is not.

## Consequences
- Easier: anyone can read the code, run it, change it and share their changes.
- Easier: the license is short and close to MIT, so it is quick to understand.
- Harder: it isn't an OSI-approved license, so the project is described as source-available.
- Harder: some companies only allow OSI-approved licenses and won't use it.
